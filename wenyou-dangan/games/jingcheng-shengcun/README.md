## 核心结论

1. 卖点在三处：题材爽点叠加、从乞丐到首富的逆袭曲线、同一事件每个男主各写一版台词。系统本身不深。
2. 主线是隐式的：几条线按「回合 + 存款 + 好感」条件交替触发，玩家总有下一件事；但界面上没有任何目标提示，也没有结局。
3. 数值基本没设计过：街市买卖同价，可以零成本无限刷名气；养猪碾压其他牲畜；药材种子种了亏本；钱庄复利不封顶；认亲一次给 1000 万文。住所的价格间隔倒是正好合适。
4. 可复用的骨架是这几样：状态对象、数据表、唯一的弹窗、事件队列、转旬流水线。已提炼进 [playbook/skeleton.md](../../playbook/skeleton.md)。
5. 新作机会：显式目标栏、多结局加图鉴、男主立绘、女性互助线、调平的经济、主角设为成年。
