# 04 · 剧情

本篇只写梗概和短引用，原文留在本地源文件里。写法上的通用结论已提炼进 [playbook/narrative.md](../../playbook/narrative.md)。

## 开局（`page.html:193`）

标题「京城生存」，副标题「一个十六岁女孩的孤勇」。处境交代：重男轻女的家里，爹要把你换给邻村老财主，拿三十两彩礼；娘说家里的钱要留给弟弟念书、娶媳妇。你什么都没说，夜里揣着几十文钱走到了京城。最后两句写世界：京城大到能藏住一个人，也冷到能冻死一个人。

进城后的第一批日志：没有人看你一眼；今夜你睡在城西的破庙里。

## 隐式主线：四条线交替触发

| 线 | 节点 | 触发 |
|---|---|---|
| 生存与住所 | 破庙 → 小木屋 → 小院子 → 大宅院 → 开铺子 | 攒钱 |
| 原生家庭 | 家书要钱 → 娘上门 → 弟弟住下 → 断亲 | 回合数 + 存款 |
| 男主好感 | 每人 4 段 | 好感 20 / 50 / 80 / 100，或婚后调查进度 |
| 婚后与子女 | 结婚 → 怀孕 → 取名 → 上学 → 科考 → 画像 → 婚嫁 | 好感、孕率、年龄 |

界面上没有任务栏，也没有结局。玩家知道下一步做什么，靠的是锁着的工作写明了门槛、住所按钮显示下一级的价格，以及剧情在攒钱的过程中不断冒出来。

另有两位女性 NPC：阿桃（酒楼帮工，洗碗时遇见）、柳娘（布庄绣娘，做绣娘时遇见）。各有一段介绍和一个秘密，但没有剧情，也不能交互，只能「去见一面」涨好感。

### 每人一组同情境台词

每个男主都写了这些情境：求婚台词、成为情人、情人吃醋、婚后吃醋、怀孕时（丈夫「惊喜」版、情人「窃喜」版）、撞见情敌、发现你去幽会。同一个情境，换个人就换动作和口癖。例：

- 怀孕时：陆时安的药杵掉在地上，先给你诊脉，「我怕这是梦」；阿福撞翻面盆，蹲着笑出眼泪；谢怀安放下磨刀石，「坐好」；顾燕先问「这孩子是我的吧？」
- 撞见情敌：谢怀安只说三个字「说清楚」；裴景行笑出声，问你他给不起什么；阿福慌着摆手，说自己只是路过。

## 写作手法（已提炼进 playbook）

1. **男主出现的位置有讲究**：诱惑总在你最得意（高薪工作）或最脆弱（当铺）的时候出现。
2. **暖男靠好感解锁，渣男要婚后调查才看得到真相**，于是自然走出「婚后识破 → 和离」。
3. **贯穿物件**：每段剧情都回到同一个小细节。
4. **最大的反转改写了开局**：捕快线揭开那对爹娘是调包孩子的养父母，难怪他们从小待你不好、舍得把你卖掉。
5. **主题在下一代回环**：孩子要娶嫁同性伴侣时，如果你反对，会想起自己当年离家时也这样跪着，被爹骂「孽障」。
6. **克制**：最动情的地方反而少写。认亲那段，捕快最后只说了一句「案子结了」。

## 随机夜间事件（`page.html:3414`）

每旬有 20% 概率触发（住破庙时 35%）：遭贼丢钱；夜里冻得睡不着（可能生病）；隔壁老妇人送一碗热粥；在墙缝里摸到铜板；美貌 ≥42 时有人在门外徘徊，你可以屏息或喊人；其余是一夜安稳。冷暖交替，呼应开局那两句。

## 设定矛盾

- 陆时安的「秘密」字段写的是「攒钱给师父赎身，那是他的生父」，剧情里却是父母双亡、给爷爷治病。
- 秘密提示字段 `secretHint` 一直没显示出来：全文件没有一处把 `secret` 设成 true，伏笔功能没做完。
- 开局说你 16 岁离家；捕快线说调包发生在「十几年前」，大体对得上。
