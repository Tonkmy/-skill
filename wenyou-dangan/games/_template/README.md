## 文件地图

| 文件 | 内容 |
|---|---|
| 01-tech.md | 技术构造：文件结构、状态、渲染、弹窗、事件、存档、资源 |
| 02-gameplay.md | 玩法：时间与行动、结算顺序、成长阶梯、各系统 |
| 03-economy.md | 数值体检：脚本输出、异常、改进建议 |
| 04-narrative.md | 主线、角色、事件、文风 |
| 05-gaps.md | 短板、机会、可复用清单 |

原创用的分篇：

| 文件 | 内容 |
|---|---|
| 01-concept.md | 定位、目标玩家、爽点、立项自检表 |
| 02-mainline.md | 主线节拍表、结局 |
| 03-systems.md | 选用的模式卡和参数 |

| 05-characters.md | 角色卡、台词矩阵 |
| 06-assets.md | 素材清单 |
