# 主线、角色与台词

## 1. 开局钩子

**公式**：一个具体的不公 + 主角沉默的行动 + 两句话写世界的冷暖。150 字以内，开局 30 秒就把恨意和「想证明自己」立住。

原作的拆法：
- 不公：重男轻女，爹要拿你换老财主三十两，娘说钱要留给弟弟念书娶亲。
- 行动：「你什么都没说」，夜里揣着几十文钱走到京城。
- 世界：京城大到能藏住一个人，也冷到能冻死一个人。

要点：不公要**具体到数字和人**（三十两、老财主、弟弟）；主角不哭不喊，直接行动；结尾一句冷，一句暖。

## 2. 主线骨架

用户评价原作「主线设计很不错，推进游戏进度，还能成长」。拆开来看，原作的主线是**几条按条件交替触发的线**，并没有任务栏：

| 线 | 推进方式 | 给玩家的目标 |
|---|---|---|
| 生存与住所 | 攒钱 → 搬家 | 搬出破庙 → 有院子 → 住大宅 |
| 原生家庭 | 回合数 + 存款触发 | 应付要钱 → 攒钱断亲 |
| 男主好感 | 好感 20 / 50 / 80 / 100 | 揭开每个人的秘密 |
| 婚后与子女 | 婚姻、孕育、科考 | 识破渣男、子女做官 |

这几条线互相错开，所以玩家几乎总有下一件事可做。新作在这个基础上补两样：**显式目标栏**（[skeleton.md §9](skeleton.md)）和**结局**。

### 主线节拍表（模板）

每部新作立项时填这张表；目标栏的内容也从这里取。

| 回合段 | 阶段目标（目标栏显示的那句） | 触发的剧情 | 解锁 | 预计收入/回合 |
|---|---|---|---|---|
| 1–3 | 活下去：吃饱，攒第一笔钱 | 开局；第一个 NPC | 第二档工作 | |
| 4–8 | 搬出破庙 | 第一封家书 | 化妆、换装 | |
| … | | | | |
| 终局 | 结局条件 | 结局 CG | 图鉴 | |

**检查**：相邻两行之间不超过 10 个回合；每一行都有一件看得见的东西被解锁（理念 1、3）。

## 3. 角色卡

每个可攻略角色或重要 NPC 填一张，结构化版本存进档案的 `data/characters.json`。

```yaml
id: lushian
名字/年龄/身份: 陆时安 / 24 / 回春堂学徒
出现: 去回春堂，第 2 回合后，90% 概率     # 放在成长阶梯的哪一格，为什么放这里
类型: 暖 | 渣 | 友
贯穿物件: 指尖的药草味                    # 一个小细节，每段剧情里都出现
表面: 话少，看人很专注
秘密/反转: 父母早亡，攒钱给爷爷治病，自卑「配不上你」
四段剧情: [好感20 寄钱, 好感50 遇见爷爷, 好感80 表白又退缩, 好感100 见家人 → 接受/婉拒]
结局选择: 接受（健康+5）/ 婉拒（好感-20，这条线关闭）
婚后: 每回合贴补 40–100
```

**配比参考**：原作 6 男 2 女，男主 4 暖 2 渣。每个渣男代表一种诱惑：一个是钱（少东家），一个是可怜（落难的世家子）。两位女性 NPC 只有一段介绍，这条线是空的，正好是新作的机会。

## 4. 台词矩阵

系统事件只写一次逻辑，每个角色各写一版台词。这是性价比最高的写法，原作的角色差异几乎都来自这里。

| 角色 \ 事件 | 求婚 | 成为情人 | 吃醋 | 夫君吃醋 | 怀孕（丈夫） | 怀孕（情人） | 撞见情敌 | 发现幽会 |
|---|---|---|---|---|---|---|---|---|
| A | | | | | | | | |

新作还可以加这几列：升职或开店时的反应、搬家、生病照顾、断亲那天、结局。

**写法**：同一句台词换个人说，一定要换动作和口癖。阿福结巴，谢怀安三个字「说清楚」，裴景行捏你下巴、似笑非笑，顾燕拖长调子。

## 5. 反转

- 原作最大的反转在捕快线：开局那对重男轻女的爹娘，其实是当年调包孩子的养父母，你是丞相府的真千金。
- **原则**：最大的反转要**改写开局设定**，让玩家回头重新理解第一屏。
- 每个角色的「秘密」在好感 20 时就要留伏笔（一道疤、一个戒痕），到好感 80–100 再揭开。

## 6. 文风

- 短句、白描，用动作代替心理描写。例：「手里的药杵『当』一声掉了。」
- 每个角色有一个口癖或小动作，贯穿始终。
- 情绪最高的地方反而少写：「他张了张嘴，最后只说了一句：『案子结了。』」
- 选项下面直接写数值后果，玩家选得明白。
- 日志（近日记事）用一句话记事，与弹窗剧情分开：弹窗写情绪，日志写事实。

## 7. 女性向爽点题材库

【判断】下面这些在女频里反复被验证过，原作一口气叠了六种：

| 题材 | 原作有没有 | 注意 |
|---|---|---|
| 大女主逆袭（乞丐到首富） | 有 | 后期要封顶，否则爽感会消失 |
| 原生家庭、断亲 | 有 | 拒绝时的舆论代价让爽点更足 |
| 识破渣男、和离 | 有 | 婚前给伏笔 |
| 真假千金 | 有 | 回扣开局 |
| 多男主、修罗场 | 有 | 合规；主角要成年 |
| 种田经营 | 有 | 数值要调平（economy.md） |
| 女性互助、姐妹群像 | 空着 | 原作的空白，新作机会 |
| 纯事业线、不靠婚恋也能通关 | 没有 | 和上一行一起，可以做成独立的结局路线 |

**合规底线**：主角成年后才开放婚恋和亲密内容。原作主角 16 岁开局，同时有行房、情人、怀孕，这一点不要照学。
