# 交付前检查清单

## 自动检查（`python scripts/audit_pptx.py deck.pptx`）

全部 ✅，或在交付说明里写明保留的理由。

- [ ] R1 没有句子式标签
- [ ] R2 彩色面积不超过模块总面积的一半，并且有 1–2 个强调元素（数据图另看）
- [ ] R3 只用 Inter，只有三档字号
- [ ] R4 只用圆角矩形；圆角只有一种；边框最多 2 种粗细；箭头只有一种粗细、一种样式
- [ ] R5 色相不超过 4 个
- [ ] R6 文字不重叠、不超出 FRAME；连线不穿过文字；相邻模块间距不小于 0.30 in

## 看渲染 PNG

通栏图印出来约缩到 60%，按这个尺寸去想象。

- [ ] 5 秒测试：遮住 caption，仍能说出这张图要讲的那句话
- [ ] 每个彩色或独立的元素都写明它是什么、干什么用；没有 head 这类没解释的术语；模型类型（如 CNN）一眼认得出
- [ ] 推理输出、损失作用位置、被训练的部分都画清楚了；结构图不写数据集名，最多标 training only
- [ ] 结构图只有结构：运算画成 ⊕ 节点、系数写在边上；数值示意放进分析图
- [ ] 视觉焦点就是创新点；视线路径和信息流一致（左→右或上→下）
- [ ] 同级模块同尺寸、同一行对齐、间距一致；连线不交叉、不穿过文字
- [ ] 记号与正文完全一致（变量名、上下标、希腊字母），术语与论文一致
- [ ] 语义颜色与其他图一致（对照项目档案）
- [ ] 数据图：数值来自数据文件，并且是最新的（对照论文 assets README 和账本的日期）；baseline 是灰色；Ours 直接标注；出图时没用 `bbox_inches="tight"`
- [ ] 最小的字印出来不小于 7 pt（note 12 pt × 0.6 = 7.2 pt）
